# Tasks

One pull request per task, on its own branch, never pushed to main. Take the first open task in
the first phase that has one, and work strictly top to bottom: most tasks touch README.md, so no
two tasks run in parallel. Each pull request ticks its own box here and appends one line to
[REPORT.md](REPORT.md) (date, task, what changed, how it was verified). Follow AGENTS.md, keep the
design exactly as it is (see [PHASES.md](PHASES.md)), and use no em or en dashes.

Card geometry, for the card tasks: every card is 590 by 190, and the status text is right-aligned
at x 558. The status dot sits at `cx = 546 - 9.4 x (characters in the status text)`, rounded to a
whole number (ALPHA gives 499, ON GITHUB gives 461, as in the existing cards). Cards 01 to 06 start
their `.tr` and `.sh` animations 1.2s apart (0s to 6.0s), so card 07 uses 7.2s and card 08 uses
8.4s. Description lines stay at or under 58 characters, the longest line on an existing card.
