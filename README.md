## 🤖 AI Engineering & Automation

This is where I do my best work — building systems where AI agents do the heavy lifting.

### Agentic Workflows
- **South African Job Agent Suite** — a multi-agent pipeline where AI agents find jobs, tailor CVs and cover letters, and auto-apply end-to-end. *(Contact me for a demo)*
- Agent orchestration patterns: planner/executor splits, tool-calling agents, and human-in-the-loop checkpoints for actions that matter.
- Prompt engineering as a discipline — structured prompts, few-shot scaffolding, and output validation instead of hoping for the best.

### Routines & Scheduled Automation
- Cron-driven AI routines that run unattended: job scraping, report generation, and health summaries delivered on schedule.
- **Server health-check automation** — scripts that monitor infrastructure and automate repetitive ops tasks ([see my repos](https://github.com/konethegreat?tab=repositories)).
- CI/CD pipelines with GitHub Actions so deployments happen without me touching them.

### API Integration & Key Management
- Hands-on with the **Anthropic (Claude), OpenAI, and Google Gemini APIs** — streaming, tool use, and structured outputs.
- Secure API key practices: environment variables and `.env` hygiene, secret managers, key rotation, scoped least-privilege keys, and **never** committing credentials to source control.
- REST and GraphQL API design, plus OAuth 2.0 / JWT auth flows on the consuming and serving side.
